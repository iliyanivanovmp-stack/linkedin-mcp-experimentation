# Technology-Based Outreach

Production downstream workflow for company rows generated by the global
`technology-stack-sourcing` skill in either `discover` or `enrich` mode.

The workbook has two tabs:

- `Companies`: verified company and technology evidence plus deterministic
  outreach context.
- `Contacts`: up to three decision makers per qualified company, including the
  copied technology variables used by Lemlist.

Run a safe dry run:

```bash
python3 run_system.py --dry-run
```

Run live:

```bash
python3 run_system.py
```

The workflow prepares context, extracts decision makers through Lemlist with
Apollo fallback, and attempts missing-email enrichment. Every eligible contact
enters `Technology-based outreach`; the same contacts also enter
`Technology-based outreach - LinkedIn only` with deterministic placeholder
emails so Lemlist can keep the campaign memberships separate.

Both campaigns share one persistent maximum of 30 total contacts per
Europe/Sofia calendar day.

The production runner is deployed as its own Modal app and is invoked by its
own daily n8n workflow. It has no scheduler, runner, or runtime dependency on
the Funnel Audit system. A manual dry-run function validates the three-company
test without writing contacts or Lemlist leads.

## Standalone operation

Run commands from this directory. All runtime and Modal deployment files are
local here:

```bash
cp .env.example .env
python3 run_system.py --dry-run --company-limit 3
PYTHONPATH=. python3 -m pytest -q
modal deploy modal_app.py
```
